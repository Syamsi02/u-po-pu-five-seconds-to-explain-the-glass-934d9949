> "That glass squatted rent-free in my sunbeam all afternoon, so I evicted it."

The program writes that single sentence to `/output/entry.txt` (UTF-8, 1–200 characters), as the make.fun program/v1 harness requires. Pure Python 3.13 standard library, deterministic — the same text on every run.
